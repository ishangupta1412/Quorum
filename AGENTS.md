It demonstrates how Midnight Blizzard (NOBELIUM) style distributed password sprays bypass traditional SIEM threshold rules and are stopped using bipartite graph clustering and multi-family consensus arithmetic.

## 3. Anti-Vibecoding Rules (Strictly Enforced)
- **NO Clichés:** No harsh rainbow gradients, purple/black marketing clichés, fake bento grids, emojis in technical data, or bouncing decorative animations.
- **Palette:** True-black canvas (`#000000`), technical slate cards (`#080C14`), 1px borders (`rgba(255,255,255,0.08)`).
- **Typography:** JetBrains Mono for all machine data (IPs, hashes, equations, timestamps). Inter / Space Grotesk for headings.
- **Semantic Color:** Color is ONLY allowed for severity (`#64748B` Low, `#F59E0B` Medium, `#EF4444` High, `#DC2626` Critical) or status (`#10B981` Resolved). Never use red or amber as decorative background accents.
- **Real Computed Data:** Every counter, timeline event, and graph node must be tied to deterministic data structures.

---

## 4. Security & Pre-Launch Directives
- **Zero Raw Credentials:** Passwords, hashes, and session tokens must never be written to disk, stored in memory, or logged.
- **Hash-Chained Audit Ledger:** All mutations must be logged to the SHA-256 hash chain (`audit_ledger`).
- **Input Validation:** All server inputs must be validated with strict Zod schemas.
- **Safe Environment Variables:** Secrets stay on server only; never expose service role keys to the browser.
